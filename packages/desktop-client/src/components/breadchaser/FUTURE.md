# Bread Chaser — parked features

The old Bread Chaser hub page was removed on 2026-07-03; its cards moved into
the Bank Sync page (Plaid), Settings (Local API), and a dedicated Email Receipts
page. Two placeholder pillars were dropped and are parked here for future work.

## Dedup review

When two sources report the same transaction — a Plaid import and an email
receipt, or two linked banks covering the same account — surface the duplicates
and let the user review and merge them in one place. The email-receipts matcher
(`loot-core/src/server/email`) already does per-source matching; this would
generalize it into a cross-source review queue.

## AI enrichment

Suggested payees, categories, and notes for imported transactions, generated by
the local model (the same Ollama setup email receipts uses). Always
**suggest-only** — surfaced for review, never auto-applied.
